# ANC project history

This page archives the **earlier project positioning**, not the current product
promise. The [current README](../README.md) describes working code and the
contemporary PHI369 Labs security research direction.

## Original Anchor concept

ANC began as **Anchor**, a coherence-weighted cryptocurrency research and
simulation project. Earlier descriptions emphasized "Beyond Speculation, Into
Resonance" and proposed **CWPoR (Coherence-Weighted Proof of Resonance)**,
including validator telemetry, bounded coherence, anti-capture weighting, and
anchor/checkpoint concepts.

A representative simulation weighting expression was:

```text
W_v = effective_stake × (1 + k_psi × bounded_coherence) × (1 - capture_risk)
```

This is a **simulation/research formula**, not evidence that coherence scores
are objectively ungameable, that validators were running a live chain, or that
a financial network was deployed.

The early design was discussed alongside the **Parallax Institute** and the
former TBRC/PhiOS/PHB research diagram. Those historical names, diagrams, and
fixed version numbers are **not** the present ANC product map.
